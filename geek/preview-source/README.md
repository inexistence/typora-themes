# Geek 预览截图说明

## 截图对应关系

- `overview.md`：选择 `Geek` 浅色主题。
- `content.md`：选择 `Geek` 浅色主题。
- `code.md`：选择 `Geek Dark` 深色主题。

## 截图设置

1. Typora 缩放设为 100%，关闭源码模式、专注模式和打字机模式。
2. 隐藏文件树与大纲侧栏，将文档滚动到顶部。
3. 点击标题栏或正文空白处，避免代码块处于编辑聚焦状态。
4. 使用与 Folio 截图相同的窗口尺寸和 macOS 窗口截图方式。
5. 分别保存为 `overview.png`、`content.png` 和 `code.png`，保留透明背景和原始分辨率。
