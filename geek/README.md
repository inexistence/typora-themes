# 极客 Typora 主题

从 `wechat-article-template` 的内置“极客 / 工程编辑部”样式移植而来。主题延续其浅灰纸张、轻量文档标题、提示卡片、方形列表、终端代码栏和细线表格，并补齐 Typora 的混合编辑、源码模式、专注模式、侧栏、弹窗与打印状态。

## 视觉特征

- `#f7f7f4` 浅灰纸张与 `#26251e` 暖黑正文，保持克制的单色工程文档气质。
- 一级、二级标题使用常规字重和紧凑字距，三级以下逐步增强字重。
- 引用使用低对比提示卡片；表格采用细边界、等宽表头和可横向滚动的宽内容布局。
- 代码块采用深色终端容器，包含三色窗口控制点、语言标签和与原模板一致的暖色语法高亮。
- 不依赖远程字体或图片资源，离线安装即可使用。

## 文件

- `geek.css`：可安装的完整 Typora 主题。
- `geek-test.md`：覆盖标题、引用、列表、任务、表格、代码、数学公式、Mermaid、脚注和打印的测试文档。
- `preview/`：用于 README 展示的 1440 × 900 主题效果图。

脚手架生成的 `geek/` 资源目录当前为空，是为未来的本地字体或图片资源保留的标准主题目录。

## 安装

1. 在 Typora 中打开“偏好设置 → 外观 → 打开主题文件夹”。
2. 将 `geek.css` 复制到主题文件夹；如果后续向 `geek/` 资源目录加入文件，也请一并复制。
3. 重启 Typora，在“主题”菜单中选择 `Geek`。

## 来源

主题视觉规则来自同级项目 `wechat-article-template` 中的内置 `geek` 主题及 `geek-manual` 渲染器。Typora 移植版针对桌面编辑环境重新实现了代码围栏、源码模式、Markdown 元字符、TOC、脚注、数学公式、图表、侧栏、搜索和打印样式。
