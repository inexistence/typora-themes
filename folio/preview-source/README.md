# Folio 预览截图说明

这三份 Markdown 用于在 Typora 中生成真实界面截图，后续再统一制作 1440 × 900 的宣传图。

## 截图对应关系

- `overview.md`：选择 `Folio` 浅色主题。
- `content.md`：选择 `Folio` 浅色主题。
- `code.md`：选择 `Folio Dark` 深色主题，并确认 Folio Enhancer 已启用，使两个代码块显示为标签组。

## 截图前设置

1. 将 Typora 缩放设为 100%，关闭源码模式、专注模式和打字机模式。
2. 隐藏文件树与大纲侧栏，让编辑区占满窗口。
3. 将文档滚动到顶部；点击标题栏或正文空白处，避免代码块处于编辑聚焦状态。
4. 三张截图保持相同的 Typora 窗口尺寸，建议不小于 1200 × 780。
5. 使用 macOS 窗口截图并保留原始 PNG，不要裁切、缩放或压缩。

完成后提供三张原始截图；宣传图会统一处理画布、留白、背景、窗口圆角与阴影。
